# Zapmap

> Zapmap Limited (company number 05960749, Bristol, United Kingdom) operates the UK's most comprehensive public electric-vehicle charging map and cross-network payment platform — 120,000+ charge points across 100+ charge point operators for 1.3 million registered drivers — and holds the Department for Transport contract to act as its electric vehicle chargepoint open data provider. Its commercial API family, Zapmap Spark (Search API, Plan API, Pay API), is described on marketing pages only: there is no developer portal, no API reference, no published base URL, no published authentication scheme, no machine-readable specification and no self-serve signup. Every route to access runs through a sales contact form and a data licence.

This file is GENERATED by API Evangelist from the catalog entry and the artifacts in this repository. Zapmap publishes no llms.txt of its own (https://www.zapmap.com/llms.txt returns HTTP 403).

## APIs (commercial, contact-sales only, no published technical surface)

- [Zapmap Spark Search API](https://www.zapmap.com/for-business/products/zapmap-spark/search-api): Charge point search over 50,000+ public charging locations in the UK and Ireland — location, live availability, kWh pricing, CPO network, power output, site facilities. No base URL, endpoints, auth scheme or spec published.
- [Zapmap Spark Plan API](https://www.zapmap.com/for-business/products/zapmap-spark/plan-api): EV route planning with configurable charging-stop selection (price, facilities, deviation). No technical surface published.
- [Zapmap Spark Pay API](https://www.zapmap.com/for-business/products/zapmap-spark/pay-api): Cross-network charging session start/stop with live cost, time and kWh across 10,000+ Zap-Pay enabled charge points. No roaming protocol named (no OCPI/OCPP reference anywhere).
- [Zapmap Spark (family overview)](https://www.zapmap.com/for-business/products/zapmap-spark)

## Notes for agents

- There is no public Zapmap API you can sign up for. Do not attempt to construct requests against api.zap-map.com — it is Zapmap's own credential-gated client backend, not a third-party product, and every path answers 401 "Missing API Key" without a Zapmap-issued credential.
- The UK Public Charge Point Regulations 2023 oblige charge point OPERATORS (not Zapmap) to publish open data. If you need open EV charging data for the UK, go to the operators or to Open Charge Map, not to Zapmap.
